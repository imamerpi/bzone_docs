# CEISA 4.0 保税仓储设施填写指南（djbc_ceisa_tpb）

> **最后更新：** 22 Oktober 2026

本文档是 **用户指南**，供进出口运营、后勤、保税报关行（PPJK）和公司海关工作人员在填写 **保税仓储设施（Tempat Penimbunan Berikat - TPB）** 的 CEISA 4.0 海关申报表单每个选项卡时参考。本指南是非技术性的，按照印度尼西亚海关最佳实践组织。

---

## 1. 基本规则与关键填写原则

在单击 TPB 单证上的 **确认（Confirm）** 按钮之前，请确保您理解三个黄金规则，以防止单证被海关服务器 **拒绝**。

### 1.1 CIF 值与货物价值不得为零（0）

CEISA 服务器自动拒绝 **CIF = 0** 或 **单价 = 0** 的单证，因为这违反了 **印度尼西亚海关法 2006 年第 17 号** 的 *交易价值* 原则。海关当局认为在海关区域内流通的任何货物，无论多小，都具有经济价值。

### 1.2 处理免费样品、礼物、保修项目和免费（FOC）项目

对于特殊情况，例如免费样品、促销礼品、保修更换或 **免费（FOC）** 装运，请勿将值留空或写零。请按以下步骤操作：

* 使用标题明确的 **形式发票（Proforma Invoice）**：**"Value for Customs Purposes Only"**。
* 根据 **市场价格**、**以前发票** 或 **生产成本数据** 分配合理的参考值。
* 在附加信息字段中添加明确的备注，例如 **"FOC"** 或 **"Free of Charge"**，以便海关审计师了解背景。

### 1.3 每周税务汇率（NDPBM KMK）

所有以印尼盾计算的海关计算 **必须** 使用财政部长每周设定的 **税务汇率（Kurs Pajak）**（通常称为 **NDPBM KMK**）。请勿使用银行的卖出价或商业交易汇率。

> [!TIP]
> 适用的汇率是 CEISA 中 **单证登记日期** 的汇率。在创建任何新的 TPB 单证之前，请确保 BZone 系统中的每周汇率已通过 **海关税务汇率（Kurs Pajak Pabean）** 菜单更新。

## 2. 表单填写分步流程

打开 **CEISA 连接器 > 海关 > TPB（CEISA Connector > Customs > TPB）** 菜单，然后选择您要创建的单证类型。按顺序遵循以下每个步骤。

### 步骤 1：单证标题选项卡

此选项卡是您的海关申报的主要标识。

* **26 位申请号（Nomor Aju）**：保存草稿时由系统自动生成。
* **监管海关办公室**：根据您的 TPB 许可证选择（例如 `040300` 表示保税区监管办公室）。
* **海关单证类型**：根据交易目的选择：

  ![BC 单证类型选择](/assets/images/ceisa_tpb_header.png)

  | BC 编码 | 简要用途 |
  |---|---|
  | **BC 2.3** | 货物进口到 TPB（来自海外的原材料 / 资本货物）。 |
  | **BC 2.5** | 成品从 TPB 销售 / 交付到本地市场。 |
  | **BC 4.0** | 本地采购到 TPB，不征收增值税。 |
  | **BC 4.1** | 从 TPB 到 TLDDP（国内海关区域）的退回 / 交付。 |
  | **BC 2.7** | TPB 间转移。 |
  | **BC 2.6.1 / 2.6.2** | 分包放行 / 退回。 |

### 步骤 2：实体选项卡

实体是交易涉及的各方。系统自动分配优先级，但您必须确认以下数据：

* **TPB 运营商（系列 1）**：必填，并自动设置为主实体。16 位 NPWP（纳税人识别号）、NIB（商业识别号）和 TPB 许可证号必须有效。
* **货主**：货物的法定所有者（可能与 TPB 运营商相同）。
* **收货人**：在目的地接收货物的方。
* **发货人**：海外供应商（用于进口）或本地供应商（用于 BC 4.0/4.1）。
* **API 类型**：为一般进口选择 **API-P**（货物进口通知），或根据海关办公室签发的许可证文件选择。

  ![海关实体表单](/assets/images/ceisa_tpb_entitas.png)

### 步骤 3：支持性单证选项卡

此选项卡包含交易的支持性单证。**系列顺序至关重要**，因为 CEISA 服务器按优先级进行验证：
1. **商业发票** - **必填系列 1**。对于形式发票，使用单证类型 `PROFORMA INVOICE`。
2. **提单（B/L）或空运单（AWB）** - 对于通过海港/机场运输的货物，**必填系列 2**。
3. **其他支持性单证** - 放在系列 2 之后，例如：装箱单、原产地证书（表格 E / 表格 D）、合同和备件清单。

  ![支持性单证系列顺序](/assets/images/ceisa_tpb_dokumen_pelengkap.png)

> [!IMPORTANT]
> 如果发票和 B/L/AWB 不在系列 1 和系列 2 中，则单证将被海关系统自动拒绝。

### 步骤 4：运输选项卡

填写货物从原产地到目的地的实际移动。

* **运输方式（Transport Mode）**：按方式选择：海运 / 空运 / 陆运。
* **运输工具名称**：船舶名称 / 航班号 / 车牌号。
* **国家旗帜代码**：使用 **ISO Alpha-2 Capital** 标准的 2 字母代码，例如 `ID`（印度尼西亚）、`SG`（新加坡）、`CN`（中国）、`JP`（日本）。
* **BC 1.1 舱单编号**：输入来自航运公司或货运代理的舱单编号。

  ![运输工具数据](/assets/images/ceisa_tpb_pengangkut.png)

### 步骤 5：包装与集装箱选项卡

填写货物的实际包装详情。

* **包装数量和类型**：使用 CEISA 标准包装代码，例如 `CTN`（纸箱）、`PK`（包）、`PLT`（托盘）、`BG`（袋）、`DR`（桶）。
* **每种类型的数量**：输入包装数量，例如 `10` 表示 `10 个纸箱`。
* **集装箱编号**：输入 **11 位集装箱编号**，如集装箱上印刷的（前缀 4 个字母 + 7 位数字）。指定集装箱尺寸和类型（20 英尺、40 英尺、45 英尺）。

  ![包装与集装箱详情](/assets/images/ceisa_tpb_kemasan.png)

### 步骤 6：交易与财务选项卡

此选项卡是 **海关计算的核心**，因为它定义了进口关税和税款的基础。

* **货币代码**：根据发票选择外币代码，例如 `USD`、`CNY`、`EUR`、`JPY`。
* **FOB 值（船上交货价）**：装货港的货物价值。
* **运费**：从原产地仓库到目的港的运输成本。
* **保险**：运输保险费。
* **CIF 值**：由系统自动计算。
* **交付价格（Harga Penyerahan）**：本地交易（BC 4.0/4.1/2.5）的以印尼盾计的交付值。
* **日期和 KMK 汇率**：根据单证日期和活动税务主数据自动填充。

  ![财务与 CIF 选项卡](/assets/images/ceisa_tpb_keuangan.png)

### 步骤 7：货物与原材料详情选项卡

填写每个货物行的项目化详情。

* **HS 编码 8 位**：根据 **印度尼西亚海关税则（BTKI）** 选择，例如 `8473.30.90` 表示计算机零件。
* **货物描述**：编写与实际货物匹配的清晰描述，以确保顺利检查。
* **CEISA 单位**：从标准单位代码中选择，例如 `PCE`（件）、`KGM`（千克）、`MTR`（米）、`LTR`（升）。
* **数量与价值**：输入数量和每个项目的 CIF 值。
* **原材料转换（BC 2.5）**：对于从进口原材料（BC 2.3）加工的成品本地销售，系统自动拉取 **原材料使用历史** 作为进口关税和关税计算的基础。

  ![货物详情与关税](/assets/images/ceisa_tpb_barang.png)

## 3. 海关计算方法与公式

本节介绍可用于 **仔细核实** 单证发送前关税和税款的简单公式。

### 3.1 基本计算公式

| 编号 | 组件 | 公式 |
|---|---|---|
| 1 | CIF 值（外币） | **CIF = FOB + 运费 + 保险** |
| 2 | CIF 值（IDR） | **CIF IDR = CIF 外币 × KMK 税率** |
| 3 | 进口关税（BM） | **BM = 关税税率 × CIF IDR** |
| 4 | 进口价值（税基） | **税基 = CIF IDR + 进口关税** |
| 5 | 进口增值税（11%） | **增值税 = 11% × 税基** |
| 6 | 第 22 条所得税 | **PPh 22 = 2.5% × 税基**（如持有 API）或 **7.5% × 税基**（如非 API） |

> [!TIP]
> **税基** 是增值税和第 22 条所得税评估的基础。确保其上方的所有组件都正确计算。

### 3.2 实际数字案例研究

以下是一个真实示例，可帮助操作人员可视化计算流程。

**进口数据：**

* 货物：100 PCE 计算机零件
* HS 编码：`8473.30.90`，进口关税：`5%`
* FOB：USD `2,000`
* 运费：USD `100`
* 保险：USD `50`
* KMK 汇率：`Rp 16,000 / USD`

**计算步骤：**

1. CIF（外币）= `2,000 + 100 + 50` = **USD 2,150**
2. CIF（IDR）= `2,150 × 16,000` = **Rp 34,400,000**
3. 进口关税 = `5% × 34,400,000` = **Rp 1,720,000**
4. 税基 = `34,400,000 + 1,720,000` = **Rp 36,120,000**
5. 增值税 11% = `11% × 36,120,000` = **Rp 3,973,200**
6. 第 22 条所得税（API）= `2.5% × 36,120,000` = **Rp 903,000**
7. **现金支付总额 = Rp 1,720,000 + Rp 3,973,200 + Rp 903,000 = Rp 6,596,200**

> [!IMPORTANT]
> 对于 **保税区的 BC 2.3**，由于保税区便利化，进口关税、增值税和第 22 条所得税 **全部被暂停并不征收**。BC 2.3 的现金支付总额 = **Rp 0**，但义务仍记录在 IT 库存中，必须通过出口或本地销售（BC 2.5）实现。

### 3.3 BC 2.5 的特殊计算规定（放行至 TLDDP / 本地市场）

**BC 2.5** 单证用于将来自 TPB（保税区）的加工产品或资本货物放行到国内市场（TLDDP）。由于海关暂停结束，企业必须支付进口关税、增值税和所得税。根据 **PMK 131/PMK.04/2018 jo PMK 65/PMK.04/2021 第 30 条**：

#### 1. 计算方法选项（`kode_perhitungan`）
系统为每个货物行提供 **计算方法（`kode_perhitungan`）** 字段：

* **选项 1：产出价格 / Harga Pengeluaran（代码 `1`）**
  * **关税评估基础（DPP BM）**：基于成品的 **交付价格 / 销售价格**。
  * **税则 / HS 编码**：使用 **成品** 的 HS 编码。
  * **公式**：
    * `进口关税 = 交付价格 × 成品关税率%`
    * `增值税（11%）= 交付价格 × 11%`
    * `第 22 条税 = （交付价格 + 进口关税）× PPh 税率%`
  * **应付款总额**：`关税值 + 增值税值 + 所得税值`。

* **选项 0：入境价格 / Harga Pemasukan（代码 `0`）**
  * **原则**：税率和征收金额参考 **原材料选项卡（`bahan_baku_ids`）** 中使用的原材料。
  * 当成品使用进口原材料（来自 BC 2.3）和本地原材料（来自 BC 4.0）的混合物时，**货物关税** 选项卡显示 **4 个不同的税 / 款行**：
    1. **进口原材料的 3 种征收类型（来自 BC 2.3）**：
       * **a. BM（进口关税）**：`Σ（CIF IDR 进口原材料 × 进口原材料关税率%）`
       * **b. PPH（进口所得税）**：`（Σ CIF IDR 进口原材料 + BM）× PPh 税率%` *（API：2.5%，非 API：7.5%）*
       * **c. PPN（进口 VAT）**：`（Σ CIF IDR 进口原材料 + BM）× 11%`
    2. **本地原材料的 1 种征收类型（来自 BC 4.0）**：
       * **d. 本地增值税（`PPNLOKAL`）**：`Σ（本地原材料价格）× 11%`
       * *（本地原材料免征进口关税和第 22 条税）*。
  * **单证标题征收表**：系统自动将所有 4 种征收汇总为应付款（便利化 `1` DIBAYAR）。

#### 2. 非进口 / 纯本地货物的处理
* 如果成品完全由本地 / 国内原材料（来自 BC 4.0 / `kode_asal_bahan_baku = 1`）制成：
  * **进口关税 = 0%（Rp 0）**
  * **第 22 条所得税 = 0%（Rp 0）**
  * **仅评估本地增值税（11%）**：`VAT = 交付价格 × 11%`。

#### 3. 第 22 条所得税规定及 CEISA API 为何不返回 PPH
* **为什么 CEISA API（`ceisa.tarif`）只返回 BM 和 PPN？**
  * CEISA OpenAPI 端点 `/openapi/tarif-hs` 查询 **BTKI（印度尼西亚海关税则）**，该税则严格按商品 HS 编码确定海关关税。
  * 第 22 条进口所得税由税务总局 / 财政部管理，基于 **纳税人实体资格（进口商 API 许可证状态）**，而不是纯粹按 HS 编码管理。因此，CEISA API **从不返回 PPH 关税行** 在 `tarif-hs` 端点下。
* **法定 2.5% 税率法律依据：**
  * 根据 **PMK No. 34/PMK.010/2017 jo PMK No. 41/PMK.010/2022**：
    * 持有 **API（进口商识别号 / NIB）** 的进口商：税基的 **2.5%** 法定税率（`PPh DPP = 交付价格 / CIF + 关税值`）。
    * **无 API** 的进口商：法定税率 **7.5%**。
    * **SKB（第 22 条税豁免证书）** 持有者：税率 **0%**（豁免便利化）。
  * 在保税区（TPB）中，所有运营企业均持有有效的 API 凭证。BZone 自动在进口货物或进口投入制成的成品上设置标准的 **2.5%** 默认值，同时为非 API 或 SKB 场景保留字段可编辑。

#### 4. 反重复 UI 机制（就地更新）
* 当用户更改 HS 编码、清除并重新选择 HS 编码，或单击 **"Tarik / Refresh Tarif CEISA"** 时：
  * BZone 映射现有评估行（`BM`、`PPH`、`PPN`），并通过 **`COMMAND.UPDATE`（`1, id, vals`）** 直接就地应用更改。
  * 之前操作的任何重复行都将通过 **`COMMAND.DELETE`（`2, id, 0`）** 自动识别和清除。
  * 如果 HS 编码被清空，行将被干净地删除，防止 Web 客户端视图中出现重复记录。

### 3.4 TPB 间转移（BC 2.7）的关税处理
与 BC 2.5 不同，**BC 2.7** 涵盖保税区 / TPB 之间的货物转移：
* **关税便利化**：进口关税 **暂停（便利化代码 3）**，VAT / 所得税 **不征收（便利化代码 5 或 6）**。
* VAT 税率记录为 $11\%$，但 **现金支付 = Rp 0**（所有分配到便利化价值），因为货物尚未进入开放国内市场。

## 4. 关税便利化代码选择指南

TPB 单证上进口关税、VAT 和所得税的每次海关评估都使用 **便利化代码** 来表示付款状态。选择错误的代码是 TPB 单证被拒绝的最常见原因。

| 代码 | 状态 | 何时使用 | 法律依据 |
|---|---|---|---|
| **1** | **已付款（Paid, Dibayar）** | 通过 BC **2.5** 从 TPB 到 TLDDP 的本地销售的进口关税。VAT / 所得税仍全额征收。 | 海关法 17/2006、HPP 税法 |
| **3** | **暂停（Suspended, Ditangguhkan）** | 通过 BC **2.3** 进口原材料到保税区的进口关税。现在不付，但记录为负债。 | PMK 131/PMK.04/2018 保税区 |
| **6** | **不征收（Not Collected, Tidak Dipungut）** | BC 2.3 的 VAT / 所得税以及通过 BC **4.0** 到 TPB 的本地采购（TPB 便利化下不征收 VAT）。 | 政府条例 147/2000 jo. PMK 131/2018 |
| **8** | **已担保（Guaranteed, Dijaminkan）** | 通过 BC **2.6.1** 到外部工厂的分包 / 维修放行的进口关税，由银行担保担保。 | PMK 272/PMK.04/2020 |
| **5** | **豁免（Exempted, Dibebaskan）** | 在 **SKA 表格 D / 表格 AK / 表格 E** 优惠关税下的进口关税。 | FTA 证书：CEPA、ACFTA、IJEPA 等。 |
| **7** | **已结清（Already Paid, Sudah Dilunasi）** | 进口关税、VAT 或所得税已预先结清（例如在单证发送前手动付款到收款银行）。 | 海关法 17/2006 |

> [!TIP]
> 在有疑问时使用此 **快速指南**：
> * 进口原材料到保税区 → **代码 3**
> * 本地采购到 TPB → **代码 6**（对于 VAT）
> * 本地市场销售（BC 2.5） → **代码 1**
> * 出境分包（BC 2.6.1） → **代码 8**
> * 优惠关税下的进口 → **代码 5**

## 5. 提交前验证清单

在单击 **发送单证（Send Document）** 之前，请确保以下所有项目都已选中以最小化 **拒绝（Rejection）** 风险。

* [ ] **26 位申请号** 自动生成，看起来合理。
* [ ] **税率日期** 与适用的 NDPBM KMK 周匹配。
* [ ] **TPB 运营商** 位于有效 16 位 NPWP 的系列 1 实体位置。
* [ ] **发票** 位于系列 1 顺序（类型 `380` / `PROFORMA`）。
* [ ] **B/L 或 AWB** 位于系列 2 顺序（类型 `705` / `740`）。
* [ ] **国家旗帜代码** 用 2 个大写 ISO 标准字母书写。
* [ ] **CIF 总额不为 0** 且等于 FOB + 运费 + 保险。
* [ ] **汇率差异** 外币 CIF 和 IDR CIF 之间的差异是乘以 NDPBM KMK（而不是银行汇率）。
* [ ] **8 位 HS 编码** 与实际货物描述匹配。
* [ ] **关税便利化代码**（1/3/5/6/7/8）适合交易类型。
* [ ] **数量和单位** 在货物选项卡中与装箱单一致。
* [ ] **数据填写的签名和声明** 已由 PPJK 或海关工作人员检查。
* [ ] **没有异常字符**（例如数字字段中的引号），通常会导致 CEISA JSON 模式解析失败。

> [!IMPORTANT]
> 如果上述任何一项不满意，请勿强制提交。使用 **确认（Confirm）** 按钮运行 BZone 内部验证，并首先修复任何显示的错误。
