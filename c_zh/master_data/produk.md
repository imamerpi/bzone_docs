# 产品主数据与物流路线

> **最后更新：** 22 Oktober 2026

产品主数据是 ERP 运营和 BZone IT 库存海关合规的核心基础。每一件入库、生产、采购或销售的物料都必须正确配置会计参数、物流路线和海关分类。

---

## 1. 创建新产品

要创建一个新的产品主数据记录：

1. 打开 **库存**、**销售** 或 **采购** 模块。
2. 进入 **产品 → 产品**。
3. 点击左上角的 **新建** 按钮。

![产品主表单视图](../assets/images/master_produk_general.png)
*图 1.1：在 Odoo 19 中创建产品主数据的表单。*

---

## 2. 常规信息配置

在主表单和 **常规信息** 选项卡中，配置以下参数：

| 参数 / 字段 | 描述与推荐值 |
| :--- | :--- |
| **产品名称（Product Name）** | 产品的官方商业名称或描述。 |
| **可销售（Can be Sold）** | 如产品销售给客户，请勾选。 |
| **可采购（Can be Purchased）** | 如产品从供应商采购，请勾选。 |
| **可用于 DJBC（Can be Used for DJBC）** | 当产品分类为海关合规商品时，自动勾选。 |
| **产品类型（Product Type）** | 选择 **Goods（Storable）**，用于跟踪库存数量的实体商品。 |
| **开票策略（Invoicing Policy）** | 根据开票策略选择 **按订货数量（Ordered quantities）** 或 **按发货数量（Delivered quantities）**。 |
| **库存跟踪（Track Inventory）** | 选择跟踪方式：*按唯一序列号*、*按批次* 或 *不跟踪*。 |
| **销售价格（Sales Price）** | 基本单位销售价格（税前）。 |
| **客户税（Customer Taxes）** | 适用的增值税（VAT）税率。 |
| **成本（Cost）** | 物料的采购成本或标准成本。 |
| **产品类别（Product Category）** | 用于定义库存估值和自动账簿科目的类别。 |
| **内部参考（Internal Reference）** | 内部零件编号或 SKU。 |
| **条码（Barcode）** | 仓库手持扫描仪使用的条码/EAN 码。 |

> [!NOTE]
> **产品类别（Product Category）** 自动决定库存估值科目以及默认的 DJBC IT 库存分类（原材料、成品或消耗品）。

## 3. 配置物流路线（库存选项卡）

路线决定了当库存被请求时，系统如何触发采购和库存移动。

1. 打开 **库存（Inventory）** 选项卡。
2. 在 **路线（Routes）** 部分，激活相应的路线：

![物流路线配置](../assets/images/master_produk_routes.png)
*图 1.2：库存选项卡中的物流路线选择（采购、MTO、生产）。*

### 运营路线说明：

* **采购（Buy）**：指示系统在库存低于补货规则阈值时自动生成采购订单草稿（RFQ）。
* **按单生产（Make to Order, MTO）**：指示系统不从常规仓库库存中取货，而是在销售订单确认后触发专门的采购订单或生产订单。
* **生产（Manufacture）**：将产品标记为通过生产订单（MO）在工厂内部生产。
* **在制品生产（Manufacture WIP）**：识别多个生产工序之间的中间在制品。
* **按订单再供应分包商（Resupply Subcontractor on Order）**：当原材料被送到外部分包商进行加工时使用。
* **直运（Dropship）**：从供应商直接发货给最终客户，无需经过内部仓库中转。

### 物理与物流参数：
* **重量与体积（Weight & Volume）**：用于运单和报关单的毛/净重量与体积。
* **客户交货前置期（Customer Lead Time）**：从订单确认到准备发货所需的工作日估算。
* **采购请求（Purchase Request）**：当库存达到最低阈值时，自动创建内部采购申请。

## 4. 海关合规参数（DJBC 信息选项卡）

对于在海关便利化方案（保税区/KB、KITE 或 KEK）下运营的公司：

![海关分类参数](../assets/images/master_produk_djbc.png)
*图 1.3：产品表单上的 DJBC 分类与 HS 编码配置。*

1. 进入 **DJBC 信息（DJBC Information）** 选项卡。
2. **DJBC 原材料（DJBC Raw Material）**：如果该项目被归类为原料/辅助材料，并须在 IT 库存原材料变动报表中强制申报，请勾选此选项。
3. **HS 编码（HS Code）**：输入用于确定税率和 CEISA 集成的 8 位国际协调编码。
4. **货物原产地（Origin of Goods）**：指定进出口报关单的原产国。
5. 点击左上角的 **保存**。

> [!IMPORTANT]
> 一致而准确的 **HS 编码** 和 **DJBC 分类** 设置对于向 CEISA 4.0 提交单证以及生成 7 份必备 IT 库存报表至关重要。
