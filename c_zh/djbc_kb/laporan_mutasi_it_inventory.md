# 7 份必备海关变动报表（djbc_kb）

> **最后更新：** 22 Oktober 2026

BZone 提供 **7 份官方对账报表**，用于根据海关与消费税总局法规 **PER-02/BC/2019** 实时合规检查。

---

## 7 份报表概览

所有报表可通过 **海关报表 > 报表（Laporan Bea Cukai > Reporting）** 访问：

1. **按报关单分类的入库货物报表**：
   按报关类型（BC 2.3、BC 4.0、BC 2.7 入库）汇总所有收货。
2. **按报关单分类的出库货物报表**：
   汇总所有离开保税区的发货（BC 2.5、BC 4.1、BC 2.7 出库、BC 3.0 PEB）。
3. **原材料与辅助材料变动报表**：
   显示期初余额、收货、生产消耗、调整和期末余额。
4. **成品变动报表**：
   显示期初余额、生产入库、发货和期末余额。
5. **在制品（WIP）位置报表**：
   跟踪生产订单上正在加工的原材料。
6. **机械与设备变动报表**：
   核算获得关税豁免或延期的生产机械及备件。
7. **废料与废品变动报表**：
   在销毁或本地处理前，监控生产废料、废品和不合格品。

---

## 报表生成（报表向导）

1. 打开 **海关报表 > 报表（Laporan Bea Cukai > Reporting）**。
2. 选择报表类型（例如 **原材料变动报表**）。
3. 在弹出的向导中：
   * **起始日期（Start Date）**：审计期间的开始日期。
   * **结束日期（End Date）**：审计期间的结束日期。
   * **输出格式（Output Format）**：在 HTML 屏幕视图、Py3o 官方模板（ODT/PDF）或 Excel（XLSX）之间选择。
4. 点击 **打印 / 预览（Print / Preview）**。

## 对账公式

> [!NOTE]
> **对账公式：**  
> **期末余额** = **期初余额** + **入库** − **出库** ± **物理调整**

* **入库**：来自由海关报关单验证的收货。
* **出库**：来自生产消耗（MO）或发货订单。
* **调整**：来自年度 IT 库存盘点中的物理计数差异。

## 数据合规指南：确保产品和交易出现在报表中

为确保库存项目和移动交易准确地反映在 **入库报表**、**出库报表** 和 **变动报表** 中，系统执行特定的运营验证标准：

![海关数据合规检查清单](/assets/images/kb_checklist_transaksi_laporan.png)

### 1. 入库货物报表的条件（Laporan Pemasukan）
入库仓库收货（*Stock Picking / Receipts*）在满足以下 4 个条件时自动符合 **按报关单分类的入库货物报表** 的要求：

* **拣货状态必须为"已完成（Done）"**：收货拣货必须验证完成（`done`）。草稿、等待或就绪状态的拣货将被排除。
* **仓库作业类型配置**：
  * 作业类型必须将 **DJBC 移动类型（DJBC Movement Type）** 设置为 `入库（in）`。
  * 不能标记为 *废料（Scrap）* 或 *调整（Adjustment）*。
* **海关单证信息完整填写**：
  * 在收货的 **海关单证（Customs Document）** 选项卡中，必须输入 **海关单证类型（Customs Document Type）**（`BC 2.3`、`BC 4.0` 或 `BC 2.7`）、**登记号（Registration Number）**（6 位）和 **登记日期（Registration Date）**。

> [!DANGER]
> 没有海关单证详情的收货被视为内部非便利化转移，将 **不会** 出现在官方海关入库报表中。

* **产品与采购估值**：
  * 产品必须具有 **内部参考 / 编码（Internal Reference / Code）**。
  * 交付数量必须大于零。
  * 与采购订单（PO）关联，自动汇总外币估值、币种代码以及参考每周 KMK 官方汇率的 IDR 换算。

### 2. 出库货物报表的条件（Laporan Pengeluaran）
出库发货（*Delivery Orders / Stock Picking*）在以下条件满足时符合 **按报关单分类的出库货物报表** 的要求：

* **发货订单状态必须为"已完成（Done）"**：发货必须完整验证。
* **仓库作业类型配置**：
  * 作业类型必须将 **DJBC 移动类型（DJBC Movement Type）** 设置为 `出库（out）`。
  * 不能标记为 *调整（Adjustment）*。
* **填写出库海关单证**：
  * 在发货订单的 **海关单证（Customs Document）** 选项卡中，必须填写 **海关单证类型（Customs Document Type）**（`BC 2.5`、`BC 4.1`、`BC 2.7` 或 `BC 3.0 / PEB`）、**登记号（Registration Number）** 和 **登记日期（Registration Date）**。
* **产品与商业估值**：
  * 产品必须具有内部参考。
  * 商业价值来自销售订单（SO）单价乘以交付数量，并按适用的 KMK 海关汇率换算。

### 3. 7 份 IT 库存变动报表的条件
为确保产品及其库存移动数量（期初余额、入库、出库、调整和期末余额）正确地显示在相应的变动报表上：

* **产品主数据要求**：
  * **启用状态的产品**：在 `product.template` 和 `product.product` 上的 `Active` 字段必须为 `True`。
  * **内部参考（产品编码）**：必填；用作海关审计识别货物的主键。
  * **保税便利化标志启用**：在 **海关 / DJBC（Customs / DJBC）** 选项卡中，**保税区（Bonded Zone, djbc_kb_ok）** 复选框必须启用（`True`）。
  * **准确的 IT 库存分类**：在产品或产品类别上分配正确的类别：
    * `原材料（Raw Material）`（`djbc_rm`）→ 显示在原材料与辅助材料变动报表中。
    * `成品（Finished Goods）`（`djbc_fg`）→ 显示在成品变动报表中。
    * `在制品（Work in Process）`（`djbc_wip`）→ 显示在 WIP 位置报表中。
    * `机械（Machinery）`（`djbc_mesin`）→ 显示在机械与设备变动报表中。
    * `废料（Scrap）`（`djbc_scrap`）→ 显示在废料与废品变动报表中。
* **库位主数据要求**：
  * 数量基于带有 DJBC 库位编码的内部库位的进出移动计算：
    * 原材料库位（`rm`）
    * 成品库位（`fg`）
    * 生产 / WIP 库位（`wip`）
    * 机械库位（`mesin`）
    * 废料库位（`scrap`）
  * 可在 **库存 > 配置 > 库位（Inventory > Configuration > Locations）** 下配置。
* **余额计算与向导期间**：
  * **期初余额**：向导 **起始日期（Start Date）** 之前所有已完成的库存移动。
  * **入库**：报表日期范围内进入指定 DJBC 库位的移动。
  * **出库**：报表日期范围内离开指定 DJBC 库位的移动。
  * **调整**：报表期间内经验证的 **库存盘点（Stock Opname）** 计数差异。

## 诊断与故障排查矩阵

| 症状 | 可能原因 | 纠正措施 |
| :--- | :--- | :--- |
| **产品完全未出现在变动报表中** | 保税区标志未启用或产品缺少内部参考。 | 打开产品记录，确保 **内部参考（Internal Reference）** 已填写，并在海关选项卡中勾选 **保税区（Bonded Zone, djbc_kb_ok）**。 |
| **产品出现在错误的变动报表中**（例如原材料显示在成品中） | 产品或类别上分配的 IT 库存分类不正确。 | 打开产品或类别，审查海关分类，并选择适当的类别（例如，从 FG 改为 RM）。 |
| **入库货物报表中未显示收货记录** | 1. 拣货未 *完成（Done）*。<br/>2. 海关单证选项卡缺少登记号/日期。<br/>3. 作业类型移动类型未设置为 `in`。 | 1. 验证拣货。<br/>2. 打开海关单证选项卡，输入报关类型（BC 2.3/4.0/2.7）、登记号和日期。<br/>3. 在库存中验证作业类型设置。 |
| **发货未出现在出库货物报表中** | 1. 发货订单未 *完成（Done）*。<br/>2. 缺少出库报关详情。 | 验证发货订单，并输入报关类型（BC 2.5/4.1/2.7/3.0）和官方海关登记号。 |
| **尽管有活动，但变动报表上的入库/出库数量为 0** | 1. 交易日期超出向导日期范围。<br/>2. 仓库库位缺少 DJBC 库位分类。 | 1. 校验并调整向导的起始日期和结束日期。<br/>2. 进入 **库存 > 配置 > 库位（Inventory > Configuration > Locations）**，打开相关库位，并分配适当的 DJBC 分类编码。 |
