# 财务与会计管理

> **最后更新：** 22 Oktober 2026

财务与会计模块管理应付账款（*供应商账单*）、应收账款（*客户发票*）、银行/现金支付以及关键财务报表（包括利润表）。

## 2. 处理供应商账单付款

对收到的供应商发票进行付款拨付：

1. 打开 **会计（Accounting）** 模块。
2. 进入 **供应商 → 账单（Vendors → Bills）**。
3. 选择一份当前标记为 **未付款（Not Paid）** 的已审批账单。
4. 在账单表单顶部点击 **付款（Pay）** 或 **登记付款（Register Payment）**。

![供应商账单付款执行](../assets/images/accounting_vendor_bill_payment.png)
*图 7.1：供应商应付账款的登记付款弹出框。*

5. 在付款对话框中：
   * **日记账（Journal）**：选择用于资金拨付的银行或现金账户。
   * **付款方式（Payment Method）**：选择付款渠道（*银行转账*、*人工*、*支票*）。
   * **金额（Amount）**：确认拨付金额。
   * **付款日期（Payment Date）**：银行借记起息日。
6. 点击 **创建付款（Create Payment）**。
7. 状态更新为 **付款中（In Payment）** 或 **已付款（Paid）**。

---

## 3. 确认与收取客户发票

确认销售应收账款与客户来款：

1. 打开 **会计（Accounting）** 模块。
2. 进入 **客户 → 发票（Customers → Invoices）**。
3. 选择一份 **草稿（Draft）** 状态的发票。
4. 校验 **开票日期（Invoice Date）** 与 **到期日（Due Date）**。
5. 点击 **确认（Confirm）** 将发票过账到应收账款。
6. 收到客户汇款后，点击 **付款（Pay）** 或 **登记付款（Register Payment）**。

![客户发票确认与收款](../assets/images/accounting_customer_invoice_confirm.png)
*图 7.2：客户发票确认与收款登记。*

7. 选择收款银行 **日记账（Journal）**、付款方式和金额。
8. 点击 **创建付款（Create Payment）**。
9. 发票状态更新为 **付款中（In Payment）** / **已付款（Paid）**。

## 4. 生成财务报表（利润表）

*利润表*（损益表）详细列示公司在特定期间内的收入、销售成本和营业费用。

### 报表生成步骤：

1. 进入 **报表 → 利润表（Reporting → Profit and Loss）**。
2. 定义报表期间：
   * 选择 **起始日期（Start Date）** 与 **结束日期（End Date）**。
   * 可选配置 **比较（Comparison）** 以与上期对比。
3. 点击 **打印（Print）** 下载官方 PDF 文档，或选择 **导出（XLSX）** 进行电子表格分析。

![利润表财务报表](../assets/images/accounting_profit_loss_report.png)
*图 7.3：带日期筛选的利润表界面。*

4. 如出现确认提示，点击 **继续（Continue）**。
5. 生成的报表可供管理层审阅和财政审计申报使用。
