# 销售业务流程（Sales）

销售工作流程涵盖报价准备、销售订单确认、自动按单生产（MTO）执行、出库发货以及客户发票生成与付款登记。

---

## 1. 销售工作流概览

```text
[ 创建报价单 ]
         │
         ▼
[ 设置 MTO 路线 / 标准库存 ]
         │
         ▼
[ 确认为销售订单 (SO) ]
         │
         ├──────────────────────────────┐
         ▼                              ▼
  [ 触发生产 / 采购 ]         [ 创建客户发票 ]
         │                       (预付款 / 常规)
         ▼                              │
  [ 出库发货 (DO) ]                    ▼
                                 [ 登记付款 ]
```

---

## 2. 创建报价与配置 MTO 路线

1. 打开 **销售（Sales）** 模块。
2. 点击 **新建（New）** 创建一份新报价单。
3. 在 **客户（Customer）** 字段下选择买方。
4. 在 **订单行（Order Lines）** 选项卡中，点击 **添加产品（Add a product）**，并指定产品、数量和单价。

![报价创建与 MTO 路线设置](../assets/images/sales_quotation_mto.png)
*图 3.1：选择按单生产（MTO）路线的报价创建界面。*

5. 对于定制或按单生产的产品：
   * 如果 **路线（Route）** 列被隐藏，请点击列标题右侧的列选项切换图标，然后勾选 **路线（Route）**。
   * 在 **路线（Route）** 下，选择 **按单生产（Make to Order, MTO）**。

> [!TIP]
> 选择 **按单生产（MTO）** 后，系统将在销售订单确认时自动生成关联的 *生产订单*（如果产品路线为 *生产*）或采购订单草稿（如果路线为 *采购*）。

---

## 3. 确认销售订单

1. 检查数量、增值税以及收货地址。
2. 点击左上角的 **确认（Confirm）**。
3. 单据状态从 **报价单（Quotation）** 变为 **销售订单（Sales Order）**。
4. 系统将自动创建一份关联的 **发货（Delivery）** 记录，可通过表单顶部的智能按钮访问。

---

## 4. 开具客户发票（创建发票）

1. 在已确认的销售订单上，点击 **创建发票（Create Invoice）**。
2. 选择开票方式：

| 发票选项 | 用途说明 |
| :--- | :--- |
| **常规发票（Regular invoice）** | 按订货数量或发货数量进行全额开票。 |
| **预付款（百分比）Down payment (percentage)** | 按百分比进行预开票（例如订单总额的 30%）。 |
| **预付款（固定金额）Down payment (fixed amount)** | 按约定的固定金额进行预开票。 |

![确认销售订单并创建发票](../assets/images/sales_order_confirmed.png)
*图 3.2：客户发票创建对话框（预付款 / 常规）。*

3. 点击 **创建草稿（Create Draft）** 生成客户发票草稿。
4. 打开草稿发票，检查 **开票日期（Invoice Date）**，然后点击 **确认（Confirm）**。

---

## 5. 登记客户付款（登记付款）

1. 在已过账的客户发票上，点击 **登记付款（Register Payment）**。

![登记客户付款](../assets/images/sales_register_payment.png)
*图 3.3：登记付款弹出表单。*

2. 填写付款参数：
   * **日记账（Journal）**：银行或现金收款账户。
   * **付款方式（Payment Method）**：银行转账或人工收据。
   * **金额（Amount）**：确认实际收款金额。
   * **付款日期（Payment Date）**：银行交易过账日期。
3. 点击 **创建付款（Create Payment）**。
4. 发票状态更新为 **付款中（In Payment）** 或 **已付款（Paid）**。
