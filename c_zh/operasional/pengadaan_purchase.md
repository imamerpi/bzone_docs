# 采购业务流程（Purchase）

采购工作流程涵盖询价单（RFQ）创建、供应商价格确认、采购订单（PO）审批、仓库收货以及供应商账单核验。

---

## 1. 采购工作流概览

```text
[ 创建询价申请 ]
           │
           ▼
[ 供应商选择与议价 ]
           │
           ▼
[ 确认采购订单 (PO) ]
           │
   ┌───────┴───────┐
   ▼               ▼
[ 收货 ]     [ 创建供应商账单 ]
(仓库库存)  (应付账款)
   │               │
   └───────┬───────┘
           ▼
[ 对账与付款 ]
```

---

## 2. 创建询价单（RFQ）

1. 打开 **采购（Purchase）** 模块。
2. 点击 **新建（New）** 打开一份新申请。
3. 在 **供应商（Vendor）** 字段中选择供应商。
4. 设置 **订单截止日期（Order Deadline）** 和 **预计到达日期（Expected Arrival）**。
5. 在 **产品（Products）** 选项卡中，点击 **添加产品（Add a product）** 指定物料、数量和约定的单价。

![新建询价单表单](../assets/images/purchase_rfq_new.png)
*图 4.1：询价单（RFQ）表单视图。*

---

## 3. 确认为采购订单（PO）

1. 在价格和运输条款确定后，点击 **确认订单（Confirm Order）**。
2. 单据状态从 **询价单（RFQ）** 变为 **采购订单（Purchase Order）**。
3. 系统自动创建一份关联的仓库收货记录，可通过 **收货（Receipt）** 智能按钮访问。

![采购订单确认视图](../assets/images/purchase_order_confirm.png)
*图 4.2：已确认的采购订单与收货智能按钮。*

---

## 4. 在仓库接收货物（收货）

1. 仓库操作员可通过 **收货（Receipt）** 智能按钮或 **库存 → 作业 → 收货（Inventory → Operations → Receipts）** 直接处理入库。
2. 核对实际收到的实物数量与订购数量。
3. 完全收货并验证后，**接收产品（Receive Products）** 按钮消失，*已收货（Received）* 数量相应更新。

---

## 5. 开具并确认供应商账单（创建账单）

1. 在采购订单上，点击 **创建账单（Create Bill）**。
2. 系统生成 **供应商账单（Vendor Bill）** 草稿。
3. 在 **账单日期（Bill Date）** 字段中指定供应商开票日期。
4. 在 **供应商参考（Vendor Reference）** 中输入供应商发票编号。
5. 点击 **确认（Confirm）**。

![供应商账单创建与过账](../assets/images/purchase_vendor_bill.png)
*图 4.3：供应商账单核验与确认表单。*

6. 账单状态转为 **已过账（Posted）**（付款状态：*未付款 Not Paid*），并在会计模块中等待付款拨付。

> [!NOTE]
> 应付账款负债与库存清算账簿分录会在供应商账单确认时自动生成。
